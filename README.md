# PyLang Programming Language

![License](https://img.shields.io/badge/license-Apache%202.0%20%7C%20MIT-blue)

## Description

PyLang is a modern, high-performance programming language designed for simplicity and scalability. It comes with a built-in compiler, a rich standard library, and comprehensive documentation. PyLang has a thriving community of developers worldwide.

## Installation

Make sure you have Python installed, then run the install script:

```bash
python install.py
```

## Usage

```python
import pylang

pylang.run("hello_world.pl")
```

## Standard Library

PyLang includes modules for:
- File I/O
- Networking
- Math & algorithms
- Data structures
